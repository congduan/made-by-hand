# CraftPlay · 做手工

Vue 3 + TypeScript 的三维磁力片拼搭场景。折纸与剪纸路由已预留。

## 运行

```bash
npm ci
npm run dev
```

打开本地 Vite 地址，拖动磁力片，拖动空白处旋转视角，滚轮缩放。工具栏可生成小房子演示或清空场景。

## 验证

```bash
npm run build
npm run typecheck
npm run verify
```

`npm run verify` 使用 Puppeteer 启动 Vite 预览，检查页面错误、小房子的几何与 8 秒稳定性，以及倾斜单片的磁条吸正。

## 物理模型

单位为厘米和秒。片边长 7.5 cm，厚 0.55 cm，重力 -981 cm/s²。每条边有一条居中的磁条，长度为边长的 70%，使用 9 个采样点。近场条对的各点对按反平方律计算，并在各自的世界采样位置施加等大反向力。`cannon-es` 的 `applyForce` 第二参数是相对质心的位置，因此引擎先将世界位置转换为相对坐标，以保留错位力矩。满足吸力、面夹角、相对速度门槛时用 `LockConstraint` 咬合。

演示小房子由 4 面正方墙和 4 片等边三角屋顶组成，预置相邻片约束后由刚体碰撞与重力稳定站立。专项测试场景使用较低的地面摩擦，以单独检验磁力矩的吸正作用。
